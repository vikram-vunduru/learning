## How This Repo Is Organized

Each technology track follows the same structure:

```
<technology>/
  00-overview-and-roadmap.md    ← what to learn, in what order, with timeline
  01-fundamentals/              ← entry-level concepts, first certs
  02-intermediate/              ← deeper topics, hands-on labs
  03-advanced/                  ← architect/expert level
  labs/                         ← real-world hands-on exercises
  resources/                    ← curated links, videos, docs, exam guides
```
