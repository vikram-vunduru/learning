## What You'll Learn

By the end of this course, you will be able to:

- Explain the difference between predictive AI and generative AI with real-world examples
- Describe how machine learning models work, including training, testing, overfitting, and model evaluation
- Identify the five Salesforce Trusted AI Principles and apply them to real-world ethical scenarios
- Explain the Einstein Trust Layer and each of its four core components (Secure Data Retrieval, Data Masking, Zero Data Retention, Toxicity Detection and Audit Trail)
- Articulate why the Einstein Trust Layer enables enterprise adoption of generative AI
- Use Prompt Builder to create, test, and activate a grounded prompt template from scratch
- Explain what "grounding" means in the context of generative AI and why it matters for accuracy
- Configure Einstein Prediction Builder to create a binary classification model with no code
- Interpret model accuracy metrics including AUC, precision, recall, and score distribution
- Set up a Next Best Action strategy that surfaces contextual recommendations on a Salesforce record page
- Identify the appropriate Einstein AI tool for a given business use case (Prediction Builder vs. Prompt Builder vs. Next Best Action)
- Explain the impact of data quality on AI model performance and describe strategies for improving training data
- Recognize and describe common types of AI bias and explain their root causes
- Navigate Salesforce Setup to find and configure Einstein AI features
- Confidently answer all five topic areas on the Salesforce AI Associate exam
