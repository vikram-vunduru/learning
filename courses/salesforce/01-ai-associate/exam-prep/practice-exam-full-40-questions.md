**Question 3**
What is the primary function of the context window in a large language model?

- A) It controls the user interface size displayed on screen
- B) It defines the amount of text (tokens) the model can process at one time
- C) It sets the maximum number of API calls per second
- D) It determines how many training examples were used to build the model

**Correct Answer: B**

**Explanation:**
- **B is correct.** The context window is the maximum amount of text — measured in tokens — that a model can receive as input and "remember" while generating a response. Conversations, documents, or prompts that exceed the context window will be truncated.
- **A is wrong.** Context window is a model architecture concept, not a UI property.
- **C is wrong.** API rate limits are separate from context windows and managed at the infrastructure level.
- **D is wrong.** Training data size is a separate concept from inference-time context window. A model's context window applies when using the model, not when training it.

**Question 5**
Which of the following best describes "zero-shot prompting"?

- B) Providing a model with examples of the desired output before asking it to perform a task
- C) Asking a model to perform a task without providing any examples of how to do it

**Question 6**
A company is deploying Agentforce for customer service. They want the AI agent to answer questions based ONLY on their approved internal knowledge base, not on general internet knowledge. Which technique should they implement?

- A) Fine-tuning the base model on the entire internet
- B) Retrieval-Augmented Generation (RAG) with their knowledge base
- C) Zero-shot prompting with explicit instructions
- D) Reducing the context window to block external knowledge

**Correct Answer: B**

**Explanation:**
- **B is correct.** RAG (Retrieval-Augmented Generation) retrieves relevant content from a specific, controlled knowledge base and provides it as context to the LLM before response generation. This grounds the AI's answers in approved content and prevents it from generating responses from general training knowledge.
- **A is wrong.** Fine-tuning on the internet would embed general internet knowledge into the model more deeply — the opposite of what's needed. Also, fine-tuning on "the entire internet" is not a practical option.
- **C is wrong.** Zero-shot prompting with instructions can help steer behavior, but it cannot reliably prevent an LLM from drawing on its training knowledge. RAG is far more effective for knowledge-grounding.
- **D is wrong.** The context window does not filter what the model knows from training — it only limits how much text can be included in a single interaction.

**Question 10**
Which statement most accurately describes the relationship between an LLM's training data and its knowledge cutoff?

- A) LLMs continuously learn from new data after deployment, so they always have current knowledge
- B) LLMs are trained on data up to a specific date; they have no knowledge of events after that cutoff unless provided in the prompt
- C) LLMs can access the internet in real time to retrieve current information by default
- D) The knowledge cutoff only applies to factual questions — LLMs can generate current creative content without limitations

**Correct Answer: B**

**Explanation:**
- **B is correct.** Standard LLMs have a training data cutoff — a date after which they have no knowledge of world events. They don't update continuously after deployment. Any information about events after the cutoff must be provided in the context window (via RAG or the user's prompt) for the model to incorporate it.
- **A is wrong.** Standard LLMs do not learn continuously from deployment usage. Their weights are frozen post-training. (Fine-tuning is a separate, deliberate process.)
- **C is wrong.** LLMs do not have real-time internet access by default. Some systems add search plugins that provide this, but it is not a native LLM capability.
- **D is wrong.** The knowledge cutoff applies broadly to all the model's knowledge — creative tasks that reference current culture, events, or people are similarly affected.

- **A is wrong.** Overfitting is a technical training problem about generalization — not a description of discriminatory outputs.

- **D is wrong.** Hallucination is fabricated content — the model is producing scores, not making up facts.
